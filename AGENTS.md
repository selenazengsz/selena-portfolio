# Selena Portfolio Website

## Project purpose

Maintain and extend Selena Zeng's English personal portfolio for full-time recruiting after her December 2026 graduation.

## Design direction

- Preserve the pastel pixel-folder visual system.
- Keep the site fully in English unless Selena explicitly requests otherwise.
- Preserve the pastel gradient, folder cards, postage-paper profile, pixel typography accents, smooth interaction, and responsive layout.
- Prefer content and data updates over redesigning the established visual language.

## Content and confidentiality

- Public company names and publicly known product names may be shown.
- Do not expose employee names, respondent-level data, internal systems, exact audience-selection rules, exact survey sample sizes, exact NPS/satisfaction values, or other non-public company metrics.
- For confidential project visualizations, use generalized labels, relative tiers, ranges, or methodology diagrams.
- Never modify the user's original resume, PDF, or spreadsheet source files.

## Important files

- `src/content.js`: portfolio text, experience, contact details, projects, and survey case-study content.
- `src/App.jsx`: page structure, project card interaction, and full-screen case-study view.
- `src/styles.css`: the pastel pixel-folder design and responsive styling.
- `public/about/profile.jpg`: Selena's profile photo.

## Working agreement

- Inspect the current website before editing.
- Keep changes localized and preserve existing behavior.
- Run `npm run build` after changes.
- Start a local preview when visual verification is useful.
- Check both the main portfolio and the clickable survey case study.
